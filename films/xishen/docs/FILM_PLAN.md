# 开篇三集制作规格

## 改编范围

原著：三九音域《我不是戏神》，番茄小说官方在线阅读第 1–6 章。分为第 1 章 / 第 2–3 章 / 第 4–6 章三集，210 / 210 / 240 秒。67 个镜头的顺序和台词见 `data/episodes.json`，生成的完整剧本见 `out/screenplay.md`。

每一集以当时的信息为边界：第一集不知道观众的规则；第二集见到观众并离家求医；第三集经医生确认异常后才试验编排情节。灰界和九座域的画面明确作为林医生讲述时的示意。开篇的陈伶会恐惧、困惑、犹疑，不使用后期身份与能力。

## 视觉设计

- 比例：1920×1080，24 fps，上下黑边形成 2.35:1 主画面。字幕单独放在下方黑边，画面不被盖住。
- 色彩：寒霜街冷蓝灰，煤油灯暖琥珀，陈伶戏袍暗朱红，观众与电子屏以克制的猩红作强调。
- 人物：共用一套人体、面部、发型和服装资产。眼睑、眉毛、嘴形、呼吸和步伐随镜头变化，不重新生成另一张脸。
- 镜头：远景建立环境，中景连接人物，面部特写保留情绪。每个镜头有缓慢推移，雨、雾、极光、追光和道具另有动作。
- 画面：全部以 Skia 及固定随机种子绘制。角色面部和建筑细节是视觉设计；原著明确的红袍、赤脚、伤口、黑棉衣、眼镜、卷烟和仪器状态保持一致。
- 行为：吞水与身后声音用半透明的听觉意象呈现，意象不作为新增人物。赵乙与小六的恋爱说法明确为制造出来的误会。

## 声音与时间

离线中文旁白与对白按镜头时钟放置。每句留出入场和收尾空隙；若声音过长，仅允许有限的无变调加速，仍不能容纳时直接报错。声音情况写入报告，不把缺失配音算作成功的必需配音版本。

配乐基于 D 小调五声素材，低音持续音与拨弦短句在剧院加强不安，在第一次编排情节时增加节奏。雨声、钥匙、门、杯子、纸张、铃声及灾厄指针破裂与对应事件对齐。对白期间压低配乐，母带目标 -16 LUFS、-1 dBTP，AAC 编码后再次测量。

## 可复现输出

每个镜头直接编码为独立 H.264 分块，只有帧数及尺寸正确的完成块可重用。分块签名由源代码、脚本及实际设置确定。最终成片包含章节和字幕轨；同时提供三集独立文件与十一分钟连续版。QC 完整解码音视频并记录可验证结果。
