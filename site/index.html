Highlights

Directed in words, made in code

🤖

Choose, personalize, render

The local Studio offers eight animated looks, editable scene cards, titles, captions, colors and three frame shapes. Choose a world and press Render to get an MP4 with original music.

🧩

Choose your renderer

Select Skia 2D, Blender 3D or an installed plugin in Studio. Stories live in films/ and media in assets/, while the framework handles picture, sound and assembly.

🎼

A shared sound toolkit

The films share a DSP library: oscillators, plucked-string and modal models, convolution reverb, a true-peak limiter and loudness helpers.

🎙️

Voices with acting direction

Use recorded dialogue or generate expressive voices locally on Apple Silicon. Scene lengths, speech and music share a timeline so you can refine the pacing.

♻️

Reproducible and configurable

Reopen films in Studio or rerun individual production steps. Override defaults with local settings. Production packs provide caching and parallelism suited to their renderers.

Quick start

Open Studio and start creating

Install Python 3.12+, Git and FFmpeg first. The commands below are for macOS and Linux. See the setup guide for Windows commands and platform dependencies.

bash
git clone https://github.com/ZJUCQR/CodeCinema.git && cd CodeCinema
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .                              # installs the `codecinema` command

codecinema studio                    # opens the local visual editor
CommandWhat it does
codecinema studioOpen the local editor, personalize scenes and render
codecinema customize <id> --renderUpdate an existing starter and render again
codecinema listThe films in films/, with their steps and requirements
codecinema run <film> <step> [args]Run one step of a film with that film's settings
codecinema new <id> [--title "…"]Create a film with its own story and central asset directory
codecinema renderersList built-in and installed renderers
codecinema checkCheck the toolchain and the Python packages

Make a film

Start your own

Eight animated looks let you produce a scenic short immediately. Use Studio to choose a renderer and edit words, timing, frames, colors and scenes. Bring your own characters and animation through Blender scenes or renderer plugins. The three-step tutorial includes exact setup commands for every platform.

Install Blender 5.2 or newer before selecting the Blender renderer.

bash
codecinema new myfilm --renderer skia --preset aurora --title "My Film" --render --open
codecinema customize myfilm --renderer blender --preset ocean --duration 20 --render
codecinema run myfilm all --quality preview  # separate preview; preserves the master

Project layout

Where things live

The framework owns rendering and production code in codecinema/. Story data lives in films/, and media is grouped by film in the root assets/ directory.

CodeCinema/
CodeCinema/
├── codecinema/             # shared filmmaking framework
│   ├── __init__.py        # package version and public convenience imports
│   ├── __main__.py        # python -m codecinema entry point
│   ├── cli/               # command-line interface
│   ├── workspace/         # film content and project management
│   ├── engine/            # shared production pipeline
│   ├── runtime/           # external tools and process support
│   ├── studio/            # local visual editor
│   ├── renderers/         # Skia, Blender and renderer plugin interface
│   ├── audio/             # music, effects, speech and performance timing
│   └── productions/       # authored example production packs
├── films/                  # independent film projects
│   ├── silvergrass/        # Duel in the Silver Grass
│   ├── nightrevels/        # The Night Revels of Han Xizai, Cat Edition
│   └── xishen/             # I Am Not the God of Drama
└── pyproject.toml          # package dependencies and all film configurations

How it works

How a film is made

One timeline connects the production. (a) Scenes live in films/, media lives in assets/, and pyproject.toml selects the renderer and production settings. (b) The framework reads scene content and timing. (c) Skia, Blender or a renderer plugin produces the picture. (d) Music, effects and optional speech follow the shots. (e) FFmpeg assembles the film and the pipeline checks output dimensions and timing. The example production packs demonstrate dedicated character, choreography, sound and quality-check workflows.
