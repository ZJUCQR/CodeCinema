两部完整的示例影片

一部是 160 秒的武士决斗，用 Blender 3D 渲染；一部是 128 秒的“活”长卷，用 2D 绘制。技术完全不同，用的是同一个框架。

🧩

约定很小，渲染器随意

影片在 film.toml 里声明步骤，codecinema run <影片> <步骤> 用这部影片的设置来运行它。Blender、矢量绘图、着色器，能输出画面帧的都行。

🎼

共享的声音工具包

两部影片配乐背后的 DSP 随框架提供：振荡器、拨弦和模态物理模型、卷积混响、真峰值限制器和响度工具。

♻️

可复现，可配置

渲染结果确定，并行任务可断点续跑，分层设置无需改动受版本管理的文件，辅助工具支持 macOS、Linux 和 Windows。

快速开始

运行示例影片

bash
git clone https://github.com/ZJUCQR/CodeCinema.git && cd CodeCinema
python3 -m venv .venv && source .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install .                                          # 安装 `codecinema` 命令

codecinema check                      # 检查 Python 依赖、ffmpeg，以及 3D 示例需要的 Blender
codecinema list                       # 列出影片和它们的步骤
codecinema run nightrevels all        # 2D 示例：几分钟生成整部影片
codecinema run silvergrass all        # 3D 示例：需要 Blender 5.2+，渲染时间较长
命令作用
codecinema list列出 films/ 里的影片，以及它们的步骤和依赖
codecinema run <影片> <步骤> [参数]用影片自己的设置运行它的一个步骤
codecinema new <id> [--title "…"]从模板开始一部新影片
codecinema check检查工具链和 Python 依赖

制作影片

开始你自己的影片

模板本身就是一部完整的小影片：draw_frame() 绘制每一帧，score() 生成声音，框架负责编码和混流。把这两个函数换成你自己的内容，再一步步扩展。完整说明见 docs/FRAMEWORK.md（英文）。

bash
codecinema new myfilm --title "My Film"     # 用模板创建 films/myfilm/
codecinema run myfilm all                    # 渲染一部 6 秒的起步影片
films/myfilm/film.toml
[film]
id = "myfilm"
title = "My Film"
entry = "src/run.py"                    # 运行影片各步骤的脚本
steps = ["render", "audio", "assemble", "all"]

[settings.video]
width = 1920
height = 1080
fps = 24

项目结构

文件都在哪里

CodeCinema/
CodeCinema/
├── codecinema/             # 框架
│   ├── cli.py              # codecinema list | run | new | check
│   ├── settings.py         # 每部影片的分层设置，工具和字体查找
│   ├── films.py            # 影片发现和步骤运行
│   ├── media.py            # ffmpeg：探测、编码、拼接、混流

│   ├── audio/dsp.py        # 共享的声音工具包
│   └── template/           # `codecinema new` 使用的起步影片
├── films/
│   ├── silvergrass/        # 示例：《芒原决战》（Blender 3D）
│   └── nightrevels/        # 示例：《韩熙载夜宴图 · 猫》（2D）
├── docs/                   # 框架说明
├── site/                   # 本主页
└── pyproject.toml          # 包和依赖

工作原理

从一个文件夹到一部电影

图 1. CodeCinema。(a) 一部影片就是一个文件夹：film.toml 声明它的步骤并保存设置，src/ 存放故事、渲染器和声音。(b) 框架用影片自己的设置运行它的步骤，并提供共享部件：分层设置、声音工具包、ffmpeg 工具、跨平台进程工具和起步模板。(c) 渲染器属于影片本身，所以两部示例用了不同的引擎：Blender 3D 和 skia 2D。(d) 每部影片的结尾都一样：编码后的画面加上母带处理过的声音，按采样精度混流成一个文件。
