CodeCinema

写下影片，运行它，观看它。Write the film. Run it. Watch it.

可扩展的通用影片制作框架。选模板，在 Studio 中个性化定制，一键生成 MP4；也可以接入自己的渲染器，组织完整的影片制作流程。

观看影片 ↓ 在 GitHub 上查看

亮点

用语言导演，用代码成片

🤖

选场景、改内容、点击出片

本地 Studio 提供八种动态场景，支持标题、字幕、颜色、时长、横竖屏和逐镜头定制。选好模板，点击生成，即可得到带原创配乐的 MP4。

🧩

约定很小，渲染器随意

影片在 pyproject.toml 里声明步骤，codecinema run <影片> <步骤> 用这部影片的设置来运行它。Blender、矢量绘图、着色器，能输出画面帧的都行。

🎼

共享的声音工具包

影片共用框架的 DSP 库：振荡器、拨弦和模态物理模型、卷积混响、真峰值限制器和响度工具。

🎙️

情绪配音与语音驱动口型

导入对白录音，或在 Apple Silicon 上本地生成带表演指令的配音。共享表演工具根据实际语音时序驱动口型，并在可用时使用音节对齐。

♻️

可复现，可配置

渲染结果确定，并行任务可断点续跑，分层设置无需改动受版本管理的文件，辅助工具支持 macOS、Linux 和 Windows。

快速开始

打开 Studio，开始制作

bash
git clone https://github.com/ZJUCQR/CodeCinema.git && cd CodeCinema
python3 -m venv .venv && source .venv/bin/activate     # Windows: .venv\Scripts\activate
python -m pip install -e .                              # 安装 `codecinema` 命令

codecinema studio                    # 自动打开本地可视化编辑器
命令作用
codecinema studio打开本地可视化编辑器，定制并一键出片
codecinema customize <id> --render修改已有起步影片并重新生成
codecinema list列出 films/ 里的影片，以及它们的步骤和依赖
codecinema run <影片> <步骤> [参数]用影片自己的设置运行它的一个步骤
codecinema new <id> [--title "…"]从模板开始一部新影片
codecinema check检查工具链和 Python 依赖

制作影片

开始你自己的影片

八种场景可直接制作动态标题短片。通过 Studio 改文字、时长、画幅、颜色和分镜，无需修改 Python；想开发新人物或新动画时再扩展绘制函数。三步出片教程提供各系统的具体安装命令。

bash
codecinema new myfilm --preset aurora --title "我的影片" --render --open
codecinema customize myfilm --preset ocean --duration 20 --render
codecinema run myfilm all --quality preview  # 预览另存，保留正式成片

项目结构

文件都在哪里

codecinema/ 提供共享工具；films/ 下每个文件夹是一部独立影片，包含自己的故事、渲染代码和制作素材。

CodeCinema/
CodeCinema/
├── codecinema/             # 共享影片制作框架
│   ├── cli.py              # 命令入口与工具链检查
│   ├── studio.py           # 本地编辑器与制作任务
│   ├── studio_assets/      # 编辑器界面与预设缩略图
│   ├── projects.py         # 项目创建、修改与备份
│   ├── starters.py         # 预设选项与分镜数据校验
│   ├── template/           # 创建新影片时复制的模板源文件
│   ├── films.py            # 发现影片并执行制作步骤
│   ├── registry.py         # 工作区影片配置管理
│   ├── settings.py         # 配置、工具与字体查找
│   ├── blender.py          # Blender 启动与共享工具
│   ├── media.py            # FFmpeg 编码与成片合成
│   ├── audio/              # 音频合成、配音与口型时间
│   ├── procutil.py         # 进程、锁与内存工具
│   └── diagnostics.py      # 依赖检查与安装提示
├── films/                  # 各自独立的影片项目
│   ├── silvergrass/        # 《芒原决战》
│   ├── nightrevels/        # 《韩熙载夜宴图 · 猫》
│   ├── xishen/             # 《我不是戏神 · 开篇三集》
│   └── beacon/             # 《守灯人》，下方展开说明
├── assets/images/          # 共用图标与 README 配图
├── site/                   # 双语项目主页与网站构建脚本
├── .github/workflows/      # CI 与 GitHub Pages 部署
└── pyproject.toml          # 包依赖与全部影片配置

一部影片内部，以《守灯人》为例：

films/beacon/
films/beacon/
├── src/                    # 本片的制作代码
│   ├── story.py            # 镜头时间线与画面、声音共用的提示点
│   ├── scene.py            # Blender 人物、场景、动画与摄影机
│   ├── sound.py            # 配乐、环境声、动作音效与混音
│   └── run.py              # 渲染、声音生成、合成与质检
├── assets/
│   ├── images/             # 海报与分镜图
│   └── film/               # 最终 TheLastBeacon.mp4（运行后生成）
└── out/                    # 渲染帧、音频中间文件与报告（运行后生成）

根目录 pyproject.toml 中的影片配置告诉框架要执行哪个脚本、支持哪些步骤；《守灯人》还在其中配置渲染采样数、曝光和角色配色。各影片的 src/ 按自己的渲染与音频流程组织，不要求文件完全相同。通过模板创建的项目另有 scenes.json，供 Studio 编辑分镜。assets/film/ 和 out/ 在运行后生成，不提交到 Git；最终 MP4 在 Release 下载。可选的个人覆盖设置放入 film.local.toml。

工作原理

一部影片是怎样制作的

图 1. 一部 CodeCinema 影片是怎样制作出来的。(a) 影片先写成数据：pyproject.toml 声明步骤和设置，一份 config 存放整个故事（时间轴、节拍、角色、写成音符的乐谱）。(b) 影片把这些数据变成场景：角色、动作编排、镜头、环境和特效，全部按同一个影片时钟打关键帧，每个动作都会发出带时间的声音事件。(c) 渲染器以并行、可续渲的分块绘制画面：一部示例用 Blender 3D，另一部用 skia 2D 绘画。(d) 配乐、音效和环境声根据音符和事件合成，再混音和母带处理。(e) 字幕、画面和声音按采样精度合成并通过质检。框架用影片自己的设置运行每一步，并提供共享的设置、声音工具包和 ffmpeg 工具。
