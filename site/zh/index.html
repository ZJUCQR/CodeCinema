CodeCinema

写下影片，运行它，观看它。Write the film. Run it. Watch it.

可扩展的通用影片制作框架。选模板，在 Studio 中个性化定制，一键生成 MP4；也可以接入自己的渲染器，组织完整的影片制作流程。

观看影片 ↓ 在 GitHub 上查看

亮点

用语言导演，用代码成片

🤖

选场景、改内容、点击出片

本地 Studio 提供八种动态场景，支持标题、字幕、颜色、时长、横竖屏和逐镜头定制。选好模板，点击生成，即可得到带原创配乐的 MP4。

🧩

选择适合故事的渲染器

在 Studio 中选择 Skia 2D、Blender 3D 或已安装的插件。剧情放在 films/，素材统一放在 assets/，框架处理画面、声音与合成。

🎼

共享的声音工具包

影片共用框架的 DSP 库：振荡器、拨弦和模态物理模型、卷积混响、真峰值限制器和响度工具。

🎙️

按情绪设计配音

使用对白录音，或在 Apple Silicon 上本地生成带表演指令的配音。分镜时长、配音与音乐共用时间轴，方便调整节奏。

♻️

可复现，可配置

在 Studio 中重新打开影片，或通过命令行重跑单个制作步骤。可用本地设置覆盖默认参数。各制作包提供适合自身渲染方式的缓存与并行策略。

快速开始

打开 Studio，开始制作

先安装 Python 3.12+、Git 与 FFmpeg。下方命令适用于 macOS 和 Linux。Windows 安装命令与各平台依赖见安装教程。

bash
git clone https://github.com/ZJUCQR/CodeCinema.git && cd CodeCinema
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .                              # 安装 `codecinema` 命令

codecinema studio                    # 自动打开本地可视化编辑器
命令作用
codecinema studio打开本地可视化编辑器，定制并一键出片
codecinema customize <id> --render修改已有起步影片并重新生成
codecinema list列出 films/ 里的影片，以及它们的步骤和依赖
codecinema run <影片> <步骤> [参数]用影片自己的设置运行它的一个步骤
codecinema new <id> [--title "…"]创建影片剧情，并配置独立的素材目录
codecinema renderers列出内置与已安装的渲染器
codecinema check检查工具链和 Python 依赖

制作影片

开始你自己的影片

八种场景可直接制作动态短片。通过 Studio 选择渲染器、调整文字、时长、画幅、颜色和分镜。自己的角色与动画可通过 Blender 场景或渲染插件接入。三步出片教程提供各系统的具体安装命令。

选择 Blender 时需要另行安装 Blender 5.2 或更新版本。

bash
codecinema new myfilm --renderer skia --preset aurora --title "我的影片" --render --open
codecinema customize myfilm --renderer blender --preset ocean --duration 20 --render
codecinema run myfilm all --quality preview  # 预览另存，保留正式成片

项目结构

文件都在哪里

codecinema/ 统一提供渲染器与制作代码。films/ 保存故事数据，媒体素材按影片统一存放在根目录 assets/。

CodeCinema/
CodeCinema/
├── codecinema/             # 共享影片制作框架
│   ├── __init__.py        # 包版本与公共便捷导入
│   ├── __main__.py        # python -m codecinema 启动入口
│   ├── cli/               # 命令行接口
│   ├── workspace/         # 影片内容与项目管理
│   ├── engine/            # 共享制作管线
│   ├── runtime/           # 外部工具与进程支持
│   ├── studio/            # 本地可视化编辑器
│   ├── renderers/         # Skia、Blender 与渲染插件接口
│   ├── audio/             # 配乐、音效、配音与表演时序
│   └── productions/       # 示例影片的制作包
├── films/                  # 各自独立的影片项目
│   ├── silvergrass/        # 《芒原决战》
│   ├── nightrevels/        # 《韩熙载夜宴图 · 猫》
│   ├── xishen/             # 《我不是戏神》
│   └── beacon/             # 《守灯人》
└── pyproject.toml          # 包依赖与全部影片配置

工作原理

一部影片是怎样制作的

一条共享时间轴连接影片制作。(a) films/ 保存分镜，assets/ 按影片保存素材，pyproject.toml 选择渲染器并配置制作流程。(b) 框架读取场景内容与时间信息。(c) Skia、Blender 或渲染插件生成画面。(d) 配乐、音效与可选配音按镜头安排。(e) FFmpeg 合成成片并检查音画时长等输出参数。示例制作包在此基础上展示专门设计的人物、动作、声音与质检流程。
